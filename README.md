# Prismatic Genesis

An HTML5 p5.js generative art game. Five switchable scenes, each a unique color palette and field physics: Nebula Bloom, Quantum Flow, Solar Bloom, Crystal Lattice, Aurora Drift.

Play: https://sixboy666.github.io/prismatic-genesis/

Open index.html in any browser. Use the scene tabs to switch physics, the seed box to explore variations, and the parameter sliders to tune.
